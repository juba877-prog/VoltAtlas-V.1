# Audit Finding EE-07: Neutral and Protective Conductor (CPC) Sizing vs. Adiabatic Thermal Withstand

## 1. Hypothesis
In VoltAtlas, neutral conductor sizing (`CableSizingEngine.kt:89-107`, `getHalfSize`) and circuit protective conductor sizing (`CableSizingEngine.kt:118-136`, `getCPCSize`) are determined exclusively by geometric / empirical lookup rules (IEC 60364-5-54 Table 54.7 for CPC and legacy workbook reduced-neutral rules). Neither conductor is ever verified against the fundamental adiabatic thermal withstand requirement ($k^2 S^2 \ge I^2 t$) mandated by IEC 60364-5-54 §543.1.2 and IEC 60364-4-43 §434.5.2. In `ProtectionEngine.kt:403-417`, the cable thermal withstand check evaluates *only* the phase conductor area (`resolveConductorArea`), completely bypassing the CPC and neutral conductors. Furthermore, for Aluminium phase cables, `getCPCSize` applies Table 54.7 without adjusting for the material conductance ratio between Copper and Aluminium. These heuristically sized conductors are then rendered in UI cards (`QuickCableCalcScreen.kt:1195-1196`) and exports as definitive, compliant engineering outputs without disclaimers or qualifications.

## 2. Evidence

   ```kotlin
   // 3. Cable Thermal Withstand Check (k^2 * S^2 >= Isc^2 * t)
   val s_mm2 = resolveConductorArea(sizingResult)
   val (cableWithstandPass, cableWithstandStatus) = when {
       s_mm2 == null || s_mm2 <= 0.0 -> false to "DATA MISSING"
       isIscMissing -> false to "DATA MISSING"

       }
   }
   ```

## 3. Reproduction / Hand Calculation

### Case 1: CPC Adiabatic Failure Under Earth Fault
- **Circuit:** 50 mm² Cu/XLPE 3-phase feeder, $I_b = 130\text{ A}$, fed from a main switchboard with prospective earth-fault current $I_{ef} = 16.0\text{ kA}$.
- **Protection:** MCCB with clearing time $t = 0.1\text{ s}$ (per `CableSizingEngine.kt:919`). Conductor insulation XLPE ($k = 143$).
- **VoltAtlas Sizing:**
  - Phase: 50 mm² Cu.
  - CPC via Table 54.7 (`getCPCSize(50.0)`): $S_{cpc} = \mathbf{25\text{ mm}^2}$.
- **Adiabatic Calculation (IEC 60364-5-54 §543.1.2):**
  $$S_{\min} = \frac{I \sqrt{t}}{k} = \frac{16000 \times \sqrt{0.1}}{143} = \frac{16000 \times 0.31623}{143} = \frac{5059.6}{143} = \mathbf{35.38\text{ mm}^2}$$
  - Thermal withstand of selected 25 mm² CPC:
    $$k^2 S^2 = (143 \times 25)^2 = (3575)^2 = 12.78 \times 10^6\text{ A}^2\text{s}$$
  - Fault energy let-through:
    $$I^2 t = (16000)^2 \times 0.1 = 256 \times 10^6 \times 0.1 = 25.60 \times 10^6\text{ A}^2\text{s}$$
  - Ratio:
    $$\frac{k^2 S^2}{I^2 t} = \frac{12.78}{25.60} = \mathbf{0.499} \implies \mathbf{FAIL}\ (-50.1\%\text{ thermal deficit})$$
- **Result:** Under a 16 kA earth fault, the 25 mm² CPC conductor temperature will exceed maximum permissible limits ($250\text{ °C}$), resulting in catastrophic insulation melting, ground-path vaporization, and potential fire. Yet VoltAtlas marks the circuit as **"✓ PASS"** and reports "Earth / CPC: 25 mm²".

### Case 2: Aluminium Conductor Material Mismatch in Table 54.7
- **Circuit:** 70 mm² Al/XLPE feeder.
- **VoltAtlas Sizing:** `getCPCSize(70.0)` returns $35\text{ mm}^2$.
- **Standard Requirement (IEC 60364-5-54 Table 54.7 Note):**
  Table 54.7 applies *only* where line and protective conductors are of the same material.
  - If the CPC is Aluminium ($k_{Al} = 94$):
    $S_{p,Al} = 35\text{ mm}^2\text{ Al}$. But VoltAtlas assumes Cu CPC in its dimension and grounding tables (`CableSizingEngine.kt:115`).
  - If line is Aluminium ($k_1 = 94$) and CPC is Copper ($k_2 = 143$):
    Equivalent conductance requires:
    $$S_p = S_{p,\text{table}} \times \frac{k_1}{k_2} = 35 \times \frac{94}{143} = 23.0\text{ mm}^2 \implies 25\text{ mm}^2\text{ Cu}$$
  VoltAtlas performs no material-aware conductance conversion.

## 4. Impact
- **Non-conservative Engineering:** Installations located near supply transformers with high fault levels ($I_{sc} > 10\text{ kA}$) will install undersized CPCs if engineers trust the app's output without separate manual adiabatic calculations.
- **Golden Fixtures Impacted:**
  All sizing test cases in `CableSizingEngineTest.kt` assert static `earthCPC_mm2` and `neutral_mm2` strings matching `getHalfSize` and `getCPCSize`. No existing test asserts adiabatic compliance of protective conductors.

## 7. Recommended Option for Owner Decision
- **Option (a) [RECOMMENDED]: Multi-Conductor Adiabatic Verification Pipeline**
  1. In `ProtectionEngine.kt:evaluateProtection`, expand the cable withstand check to evaluate all three conductor categories:
     - Phase conductor: $k_{\text{phase}}^2 S_{\text{phase}}^2 \ge I_{sc,3\phi}^2 t$
     - Neutral conductor: $k_N^2 S_N^2 \ge I_{sc,L-N}^2 t$
     - CPC conductor: $k_{cpc}^2 S_{cpc}^2 \ge I_{ef}^2 t$ (where $I_{ef}$ is derived from ADS earth fault calculation or 3-phase fault level).
  2. If the Table 54.7 CPC size fails the adiabatic equation, automatically bump $S_{cpc}$ to the minimum standard size that satisfies $S \ge \frac{I\sqrt{t}}{k}$, or flag `CPC_ADIABATIC_FAIL`.

- **Option (b): Transparent Heuristic Disclosure & Labelling**
  Retain current Table 54.7 and reduced-neutral logic, but:
  1. Update UI cards, SLD tooltips, and PDF exports to clearly label them:
     - `"Neutral: X mm² (Preliminary — Geometric)"`
     - `"Earth/CPC: Y mm² (Table 54.7 — Subject to adiabatic check)"`
  2. Emit an explicit result warning on every calculation: `"Protective conductor (CPC) sized per IEC 60364-5-54 Table 54.7; final adiabatic withstand (k²S² ≥ I²t) must be verified against actual protective device let-through energy."`

## 10. Owner Decision and Resolution (2026-10-06)

### Owner Decision: D-EE-07 = APPROVE OPTION B — TRANSPARENT STANDARD DISCLOSURE

The owner formally reviewed the technical forensic audit and **REJECTED** the earlier Deep Research proposal ($S_{\text{effective}} = S_{\text{phase}} + S_{\text{neutral}} + S_{\text{cpc}}$):
1. **Physical & Circuit Invalidation:** Neutral and CPC are not parallel conductors with phase conductors. Under earth faults ($L-PE$) or line-to-neutral faults ($L-N$), current flows in a closed loop through the active conductors in series. Summing conductor areas falsely inflates thermal withstand energy ($S^2$) by 4× to 16×, creating severe safety risks.
2. **Topology Limitation:** The current branch-circuit architecture does not model independent $I_{sc,L-N}$ or branch-specific $I_{ef}$ fault currents needed for conductor-by-conductor adiabatic checks. Fabricating synthetic fault currents is strictly forbidden.
3. **Protected Files Constraint:** `ProtectionEngine.kt` and `ShortCircuitEngine.kt` are Tier-F protected and remain untouched.

### Approved Scope of Option B:
1. **UI & PDF Disclosures:**
   Add transparent disclosure to `ProtectionScreen` and `Sections.kt`:
   *"CPC sized per IEC 60364-5-54 Table 54.7 geometric method. Separate CPC adiabatic fault withstand verification is not performed when conductor-specific fault-current model is unavailable."*
2. **User Override Activation & Validation:**
   In `CableSizingEngine.kt`:
   - Validate and activate `circuit.overrideNeutralSize` and `circuit.overrideEarthSize`.
   - Reject invalid/non-standard sizes safely with `CableFailureCode.INCOMPLETE_INPUT`.
   - Apply valid overrides to `neutralSize` and `cpcSize` in `SizingResult`.
3. **Phase Conductor Withstand Invariance:**
   Phase conductor thermal withstand check in `ProtectionEngine` evaluates phase conductor area only ($k^2 S_{\text{phase}}^2 \ge I_{sc}^2 t$) and is strictly invariant to neutral/CPC overrides.
